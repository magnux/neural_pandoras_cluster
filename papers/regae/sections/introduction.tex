\section{Introduction}

The suggestion that a neural network ``only memorizes'' its training data leaves open a practical question: what must a model learn to reproduce a complex dataset, and where is that information stored? Even a single sufficiently large image contains structure at several scales. A model can reproduce local colors, textures, and objects while failing to recover their larger arrangement. Studying this gap provides a concrete way to separate a repertoire of appearances from a representation of their relationships.

We use a large image of Pandora's Cluster as such a setting. The task is visually simple to state: learn from the image and generate extended views that retain its spatial character. It is less simple to implement. A patch autoencoder stores information partly in shared network parameters and partly in the code assigned to each patch. Decoding the original codes in their original order supplies the arrangement externally. Sampling codes without that arrangement is a different problem. Familiar-looking patches alone do not identify which configurations belong together.

Regenerative Autoencoders (ReGAE) address this distinction through two learning stages. The first stage combines an encoder with a conditional denoising decoder. It learns to restore a clean $32\times32$ image patch from a corrupted input and its learned representation. The second stage learns a denoiser over spatial windows of these representations. We call this second network the \emph{Gencoder}: it models how latent content is organized and how it changes under a small displacement of the image window. The decoder and Gencoder share an architecture family, with separately trained parameters and different channel dimensions.

The displacement is central to the construction. A shift by an integer number of latent cells leaves much of a window's code array directly reusable. Instead, we encode the image on several interleaved grids and train the Gencoder to predict the next grid. A displacement of approximately one quarter of an image patch changes the image support of every target code. Input and target still overlap strongly in pixel space, but the target requires predicting encodings of newly positioned crops throughout the window. Denoising and spatial prediction therefore form a single objective.

At generation time, the Gencoder repeatedly predicts overlapping windows of a latent canvas. Averaging their predictions combines multiple local views of the next state. The image decoder renders the resulting codes into RGB patches. Global coordinates in the original image are never supplied to the Gencoder. Any sustained traversal must arise from the content available in its current state. This creates an informative limitation: visually similar regions may not uniquely identify a continuation, allowing trajectories to depart from one source context and enter another.

This work extends the investigation of learned reconstruction dynamics in Neural Cellular Automata Manifold (NCAM)~\cite{ncam}. Here, regeneration means reconstruction under corruption, including reconstruction from noise when a patch code is available. The implementation uses multiscale networks and attention rather than retaining a strictly local cellular update rule. Its contribution is the combination of conditional patch regeneration, spatial latent prediction on displaced grids, and overlapping recurrent generation. We examine that combination as an exploratory single-image case study, with particular attention to what the code and preserved outputs substantiate.

The following sections place ReGAE beside denoising autoencoders, DiffAE, and single-image generative models; specify the implemented objectives and sampler; and discuss the existing evidence. A final discussion examines multiplicative gating, content-dependent traversal, architectural recursion, and the compression interpretation that connects these ideas. The aim is to preserve a concrete research direction with a precise account of its present scope.
