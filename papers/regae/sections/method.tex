\section{Regenerative Autoencoders}
\label{sec:method}

A conditional ReGAE separates a description of what should be reconstructed from the mutable state on which reconstruction operates. Consider a sample whose encoding is retained while its current reconstruction is corrupted. The code still supplies a reference; the denoiser uses that reference and the altered state to predict a corrected state. The same interface also accepts a noise initialization. Figure~\ref{fig:architecture} shows the conditional and unconditional forms.

\subsection{A code and a mutable state}

Let $\mathcal X$ be a space of data tensors and $\mathcal Z$ a latent tensor space. An encoder $E_\phi:\mathcal X\to\mathcal Z$ produces $z=E_\phi(x)$ for a sample $x$. A conditional denoiser maps a current state $u$ and that code back to the data domain:
\begin{equation}
 D_\theta:\mathcal X\times\mathcal Z\to\mathcal X,
 \qquad u_{k+1}=D_\theta(u_k,z).
 \label{eq:family-recurrence}
\end{equation}
The latent is a vector or structured tensor chosen for the task. Its role is to retain sample information through a bottleneck. The state has the same dimensions at every update, so the output can be reused without re-encoding. Both the code and the network parameters remain fixed along a conditional trajectory.

\subsection{Direct prediction without a clock}
\label{sec:direct-map}

The output of $D_\theta$ is the predicted target state itself. Its induced displacement at fixed $z$ is
\begin{equation}
 \Delta_z(u)=D_\theta(u,z)-u,
 \qquad u_{k+1}=u_k+\Delta_z(u_k).
 \label{eq:direct-displacement}
\end{equation}
The second expression rewrites direct assignment; the displacement is not an additional trained output. In particular, no predicted derivative or noise estimate has to be converted into the next state by a separate sampling rule.

The update counter $k$ is not a network input. Neither is the corruption strength. The same state and code therefore invoke the same correction regardless of where they occur in a trajectory. This gives an autonomous discrete map for each fixed code. It also gives a simple interface for repair: the current state can be submitted again without assigning it a time in a denoising schedule. The implications of this choice for the landscape interpretation are discussed in Sec.~\ref{sec:geometry}.

\subsection{Learning to restore a desired state}

Training presents a corrupted sample and asks for its clean counterpart. With corruption strength $\alpha$ and random variable $\epsilon$, one possible corruption is
\begin{equation}
 C_\alpha(x,\epsilon)=(1-\alpha)x+\alpha\epsilon,
 \qquad 0\leq\alpha\leq1.
 \label{eq:family-corruption}
\end{equation}
The encoder and conditional denoiser can be trained jointly with
\begin{equation}
 \mathcal L_{\mathrm{cond}}=
 \mathbb E_{x,\alpha,\epsilon}
 \!\left[\ell\bigl(D_\theta(C_\alpha(x,\epsilon),E_\phi(x)),x\bigr)\right].
 \label{eq:family-conditional-loss}
\end{equation}
Here noise is corruption of the desired state, while the regression target is that state. Sampling different strengths trains the same map on different degrees of departure from the target. The predictor must resolve uncertainty about corruption strength using the state and code; Appendix~\ref{sec:geometry-notes} gives a squared-error interpretation.

The loss $\ell$ may be $L_1$, squared $L_2$, or a feature-space loss. The Pandora image model uses a VGG-based \emph{perceptive}, or perceptual, loss~\cite{vgg,perceptual}; this is a fidelity choice for that implementation. The corruption distribution, masking, and internal architecture are likewise configurable. A U-Net-based denoiser is the default here, but the essential interface is matching state-input and state-output dimensions. Suitable operators can realize it for one-, two-, or three-dimensional layouts.

\subsection{Generation, regeneration, and conditioning}

Conditional generation starts with $u_0$ drawn from a noise distribution and applies Eq.~\eqref{eq:family-recurrence}. A code obtained from an observed sample supplies its reconstruction target. New codes require a sampling mechanism of their own. For a reconstructed state $\widehat x$ and an external perturbation $P$, regeneration instead starts with
\begin{equation}
 y_0=P(\widehat x),\qquad y_{k+1}=D_\theta(y_k,z).
 \label{eq:family-regeneration}
\end{equation}
Generation and repair thus share the learned operator. Training a restoration step supplies this reusable mechanism; successful recovery over a chosen sequence of updates depends on the learned map and the perturbations encountered. The interface alone does not establish a stable attractor.

An unconditional member removes the external code:
\begin{equation}
 u_{k+1}=D_\psi(u_k),\qquad
 \mathcal L_{\mathrm{uncond}}=
 \mathbb E\!\left[\ell(D_\psi(C_\alpha(x,\epsilon)),x)\right].
 \label{eq:family-unconditional}
\end{equation}
Its current state supplies the sample-specific context. Consequently, recovery from an ambiguous state need not identify one particular original sample. Both variants omit time conditioning; only the conditional variant receives $z$. Noise refresh or other interventions between calls are sampling choices outside the neural map.

\subsection{Making representations objects of learning}
\label{sec:composition}

After learning $E_\phi$, we can construct a dataset of representations. Let $\mathcal I_j$ index related samples and let $A_j$ assemble their indexed codes according to a supplied layout or relation:
\begin{equation}
 R_j=A_j\bigl((E_\phi(x_i))_{i\in\mathcal I_j}\bigr).
 \label{eq:representation-data}
\end{equation}
The selection and assembly specify which relationships training preserves. In the Pandora example, $A_j$ preserves spatial order; a collection of independent images would suggest a different organization. With the encoder fixed, another ReGAE can learn a state update over these tensors. We denote the unconditional instance by $G_\psi$ and call it the Gencoder.

This reuses the modeling interface across levels, with separately trained weights. Within a level, recurrence repeatedly updates a state; across levels, composition makes one model's representations the data of another. Figure~\ref{fig:representation-model} distinguishes these operations. The present construction realizes two levels. Further encoders and denoisers could extend the pattern, with each new representation and objective specified explicitly.

The higher-level target can also describe a transition. For related, same-shaped tensors $(R^-,R^+)$, train
\begin{equation}
 \mathcal L_{\mathrm{pair}}=
 \mathbb E\!\left[\ell(G_\psi(C_\alpha(R^-,\epsilon)),R^+)\right].
 \label{eq:family-paired-target}
\end{equation}
Ordinary restoration sets $R^+=R^-$. The Pandora Gencoder uses a displaced view instead, coupling denoising to prediction. Its recurrent behavior is therefore intended to progress through image content, rather than settle on one unchanged view.
