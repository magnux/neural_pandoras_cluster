\section{Regenerative Autoencoders}
\label{sec:method}

\subsection{Network architectures and their roles}

Two network architectures recur in the ReGAE family. An \emph{encoder} maps a sample to a compact representation; a \emph{denoiser} takes a state and predicts a corrected state of the same shape. What each network does in a model depends on how it is connected and trained. In an autoencoder, the encoder produces the code and the denoiser serves as the \emph{decoder}: it interprets that code to reconstruct the sample. The same encoder architecture could instead feed a classification head that predicts a label. Likewise, a denoiser can generate codes rather than decode them. We call the denoiser in that role the \emph{Gencoder}. Figure~\ref{fig:architecture} shows how a denoiser can operate with or without a separate conditioning code.

\subsection{Decoding, generation, and regeneration}
\label{sec:direct-map}

Let $x\in\mathcal X$ be a sample and let $z=E_\phi(x)\in\mathcal Z$ be the code produced by the encoder. Depending on the task, $z$ may be a vector or a structured tensor. The decoder takes $z$ and a current estimate $u_k\in\mathcal X$ of the sample:
\begin{equation}
 D_\theta:\mathcal X\times\mathcal Z\to\mathcal X,
 \qquad u_{k+1}=D_\theta(u_k,z).
 \label{eq:family-recurrence}
\end{equation}
Starting from noise asks the decoder to generate a reconstruction from the code. Starting from a damaged reconstruction asks it to repair that reconstruction. If $P$ perturbs a reconstructed sample $\widehat x$, the repair loop is
\begin{equation}
 y_0=P(\widehat x),\qquad y_{k+1}=D_\theta(y_k,z).
 \label{eq:family-regeneration}
\end{equation}
The encoder need not run again: the damage changes the state while the reference code stays fixed. How much damage the decoder can repair depends on the learned map; Appendix~\ref{sec:geometry-notes} gives a sufficient local condition.

The decoder predicts its next state directly. Its update can equivalently be written as a displacement:
\begin{equation}
 \Delta_z(u)=D_\theta(u,z)-u,
 \qquad u_{k+1}=u_k+\Delta_z(u_k).
 \label{eq:direct-displacement}
\end{equation}
Only the state prediction is trained. The decoder receives neither the update index $k$ nor the corruption strength: given the same state and code, it makes the same prediction whether it is generating or repairing. Section~\ref{sec:geometry} compares this update with time-dependent generative dynamics.

\subsection{Learning the state update}

To train the autoencoder, we encode a clean sample $x$ and separately corrupt a copy. For example, with noise $\epsilon$ and strength $\alpha$, we can use
\begin{equation}
 C_\alpha(x,\epsilon)=(1-\alpha)x+\alpha\epsilon,
 \qquad 0\leq\alpha\leq1.
 \label{eq:family-corruption}
\end{equation}
The encoder and decoder jointly minimize the error between the predicted and clean samples:
\begin{equation}
 \mathcal L_{\mathrm{cond}}=
 \mathbb E_{x,\alpha,\epsilon}
 \!\left[\ell\bigl(D_\theta(C_\alpha(x,\epsilon),E_\phi(x)),x\bigr)\right].
 \label{eq:family-conditional-loss}
\end{equation}
As the corruption strength increases, less of the target is visible in the state and the code becomes more useful. The loss $\ell$ can measure error directly (e.g., $L_1$ or squared $L_2$) or compare features. For the Pandora image decoder we use a VGG-based perceptual (\emph{perceptive}) loss~\cite{vgg,perceptual}. The choice of loss and corruption depends on what the reconstruction should preserve.

To train a denoiser without a separate code, we omit the encoder and give the network only the corrupted state:
\begin{equation}
 \begin{aligned}
 u_{k+1}&=D_\psi(u_k),\\
 \mathcal L_{\mathrm{uncond}}&=
 \mathbb E\!\left[\ell(D_\psi(C_\alpha(x,\epsilon)),x)\right].
 \end{aligned}
 \label{eq:family-unconditional}
\end{equation}
In this unconditional ReGAE, any clues to the identity of the target must come from the state itself. If several samples are compatible with what survives a perturbation, no external code selects between them. Both forms require matching state input and output dimensions, so the same construction applies to one-, two-, or three-dimensional data. We use a U-Net-based denoiser; other architectures that preserve the shape of the state can serve the same roles.

\subsection{The Gencoder: generating learned codes}
\label{sec:composition}

A decoder tells us how to turn a code back into a sample. It does not tell us which codes occur together. We can make that a separate learning problem by fixing the trained encoder and assembling its outputs into new training examples. Let $\mathcal I_j$ index a group of related samples and let $A_j$ record the relation we want to retain:
\begin{equation}
 R_j=A_j\bigl((E_\phi(x_i))_{i\in\mathcal I_j}\bigr).
 \label{eq:representation-data}
\end{equation}
For an image, $A_j$ can place patch codes in their original spatial order, giving a window of codes $R_j$. For a collection of independent samples, a useful relation might instead be membership in the same class. The choice determines which relationships the next model has an opportunity to learn.

In the Pandora case a second denoiser, $G_\psi$, serves as the Gencoder (Fig.~\ref{fig:representation-model}). Its input and output are both windows of codes, and it receives no separate conditioning code. We train it on pairs of same-shaped windows $(R^-,R^+)$:
\begin{equation}
 \mathcal L_{\mathrm{pair}}=
 \mathbb E\!\left[\ell(G_\psi(C_\alpha(R^-,\epsilon)),R^+)\right].
 \label{eq:family-paired-target}
\end{equation}
Choosing $R^+=R^-$ would train it to restore the same view. Instead we take $R^+$ from a slightly displaced view, so the Gencoder must both correct the corruption and predict the next set of codes. Each predicted code can then be rendered by the image decoder.

Two kinds of reuse are at work here. Feeding a prediction back into the same denoiser is recurrence within a single representation. Training another denoiser on the first model's codes is \emph{meta-modeling}: structure expressed in a learned representation becomes the subject of a further model. The two networks reuse the denoising architecture with separately learned parameters.
