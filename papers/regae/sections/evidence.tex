\section{Pandora's Cluster: A Worked Case Study}
\label{sec:evidence}

\subsection{One image, two kinds of information}

Pandora's Cluster provides a concrete setting in which reconstructing samples and modeling their relationships are visibly different tasks. The dataset is a rendered RGB mosaic from the James Webb Space Telescope's NIRCam instrument~\cite{webb}, with recorded dimensions of $17{,}644\times13{,}422$ pixels, or 236.8 megapixels. Its patches contain local appearances, while their arrangement carries larger structures. The task concerns visual representation and synthesis from a display composite, rather than inference from raw astronomical measurements.

If an autoencoder reconstructs every patch from its code, retaining those codes at their source locations supplies the image's arrangement externally. Sampling plausible individual patches does not supply that arrangement. This case therefore asks what changes when the learned representation itself becomes the data for another model. Figure~\ref{fig:representation-model} illustrates this transition from modeling image samples to modeling their encoded relationships.

\subsection{The first model supplies a representation}

A conditional ReGAE jointly learns an image encoder and a denoiser. The encoder maps each $32\times32$ RGB patch to 256 latent values. Given that code and a corrupted pixel state, the denoiser predicts the clean patch. The image objective is a VGG-based \emph{perceptive} loss~\cite{vgg,perceptual}, using pretrained visual features to favor perceptually similar reconstructions. These dimensions and this loss instantiate the family for the present task.

Training samples a range of corruption strengths, connecting reconstruction from nearly pure noise with correction of partially preserved content. The resulting state-to-state interface can also receive a perturbed reconstruction while retaining its conditioning code. The first model thus supplies both a representation of each patch and a process for rendering or refining it. Its reconstruction objective does not explicitly teach the arrangement of distinct patch codes.

\subsection{The Gencoder models the learned code field}

With the first model fixed, its encoder produces spatial fields of patch codes. A second ReGAE, the \emph{Gencoder}, learns on windows of these fields. It reuses the denoiser architecture family with separately trained parameters and omits the encoder-derived conditioning pathway. Its $32\times32$ latent input and output windows have the same shape; decoding one produces a $1024\times1024$ image region. The current window supplies context even though no external code identifies the desired region.

The target introduces prediction into this denoising problem. Each target window is encoded from image crops displaced by a fraction of a patch in both spatial axes. Consequently, every target code has different pixel support, although the input and target image regions overlap substantially. This discourages copying most input tokens and generating only an exposed border. The clean target is the representation of the next view, so a successful update couples correction with spatial progression.

The Gencoder receives no global source-image coordinates. Its internal positional tensors distinguish locations within a window, while navigation through the source must be inferred from content. Exact offset grids, objectives, and optimization settings are specified in Appendix~\ref{sec:implementation}. At this level, the object being learned is the structure of the first model's representations.

\subsection{From latent updates to an image sequence}

Sampling maintains a latent canvas and applies the Gencoder to overlapping windows. Each window prediction reads the preceding canvas, and averaging overlapping predictions gives its next state. Noise refresh introduces variation during this recurrent process. The shifted training target provides the mechanism for progression; the sampler does not explicitly translate the canvas to enforce motion.

The image denoiser then renders the generated codes. In the final saved video routine, each RGB patch uses one denoiser call from fresh pixel noise, while latent states are updated recurrently. Previous RGB frames are not fed back. The routine therefore exercises recurrence in representation space and uses a single-call rendering shortcut in image space; it is not a recorded pixel-space perturb-and-recover test. Its configured output is $1080\times1920$ video at 16 frames per second.

\subsection{What the existing record supports}

The author reports that local sampling reproduced star-field appearance without reliably recovering the source's larger organization. Sampling the latent model produced larger coherent views resembling Pandora's Cluster, with stochastic variations and a noisy texture compared informally to VHS video. Occasional apparent relocations, termed \emph{teleportation}, suggest ambiguity when different source regions have similar content. This is a proposed explanation of the observations, rather than an established cause.

The archive preserves decreasing training-loss traces for both models (Appendix~\ref{sec:traces}); generated stills and videos from the existing runs have yet to be incorporated. The traces document optimization of the reconstruction and shifted-prediction objectives, but do not measure controlled regeneration, exact recovery of the source arrangement, or comparative performance. The historical notebooks also contain mixed-version sampling code, so the explanatory progression above is not a controlled comparison between notebook versions (Appendix~\ref{sec:archive}). The supported construction is a model of image samples followed by a model of their learned representation field. This makes the recursive modeling proposal concrete without equating visual resemblance with complete recovery of dataset information.
