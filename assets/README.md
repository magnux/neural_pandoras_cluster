# Research assets

Selected figures, videos, and checkpoints will be connected to the notebook versions and runs that produced them. No generated research images, videos, or checkpoint files are bundled in this initial commit.

Small publication figures can be placed in this directory. Large checkpoints and videos can be linked from a suitable release or external archive once their locations are selected; generated binaries are excluded from ordinary Git tracking by default.

For each asset, record:

| Field | Purpose |
| --- | --- |
| Identifier and path or URL | Stable reference from a manuscript or research note |
| Notebook version and configuration | Model, latent width, growth stage, sampling settings, and relevant source commit |
| Training run or checkpoint | Connection to the actual saved experiment, when known |
| Description and intended claim | What the asset shows and the limits of that interpretation |
| Provenance | Original creation date if known, source image credit, and any cropping or editing |
| Checksum | Integrity check for a downloadable binary |

Priorities are ReGAE reconstruction examples, comparable sampling examples, the Gencoder video, and later NVD shrink logs or checkpoints if available. The author reports that recordings and checkpoints of the early "neural black holes" behavior were not retained; that observation will be documented as design history.
